# Приложение студии

## Purpose

`apps/studio` — SPA, в которой разработчик наблюдает виджет как его увидит хост: выбирает виджет и сценарий, переключает тему и режим отображения, видит RPC-трассу. Состояние UI живёт в Zustand и не переживает перезагрузку. Всё протокольное студия спрашивает у единственного экземпляра `HostAdapter`.

## Requirements

### Requirement: Загрузка манифеста с fallback на демо
При старте студия SHALL запросить `/api/manifest`; если ответ не JSON, не `ok` или список пуст, SHALL показать встроенный демо-виджет (HTML `kpi-card.html` из example-server, импортированный через `?raw`) со сценариями `default`, `loading`, `error`, `live`.

#### Scenario: Запуск через CLI
- **WHEN** `/api/manifest` возвращает JSON с виджетами
- **THEN** студия показывает их, активен первый

#### Scenario: Plain vite dev
- **WHEN** `/api/manifest` отдаёт SPA-страницу вместо JSON
- **THEN** студия показывает демо-виджет KPI

### Requirement: Состояние выбора
Хранилище SHALL держать `widgets`, `activeWidgetId`, `scenario`, `hostContext`, `log`. Смена виджета SHALL выбирать его первый сценарий и очищать лог; смена сценария SHALL очищать лог; патчи контекста SHALL сливаться в текущий.

#### Scenario: Переключение виджета
- **WHEN** пользователь выбирает виджет `table` со сценариями `{ main }`
- **THEN** `scenario === 'main'` и `log` пуст

### Requirement: Ограниченная трасса со стабильными ключами
Лог SHALL хранить не более 500 записей, отбрасывая старейшие; каждая запись SHALL получать монотонный `seq`, используемый как ключ React, чтобы раскрытая строка не показывала чужой payload после сдвига.

#### Scenario: Переполнение
- **WHEN** добавлено 510 событий
- **THEN** в логе 500 записей с уникальными `seq`
- **AND** `seq` уцелевшей записи не изменился

### Requirement: Панель управления из источников правды
Селектор «Widget» SHALL появляться при более чем одном виджете. Опции «Theme» SHALL браться из `hostContextSchema.shape.theme.options`, опции «Display» — из `adapter.capabilities().displayModes`; значения из `<select>` SHALL проходить через `schema.parse`, а не приведение типов.

#### Scenario: Один виджет
- **WHEN** манифест содержит один виджет
- **THEN** селектор «Widget» не отображается

#### Scenario: Смена темы
- **WHEN** пользователь выбирает `dark`
- **THEN** контекст в хранилище получает `theme: 'dark'`

### Requirement: Холст рендерит через адаптер
Canvas SHALL строить iframe из `adapter.buildIframeEnv(source, hostContext)`: `sandbox` из `env.sandbox`, `srcDoc` или `src` по `env.mode`, атрибут `csp` при наличии. Iframe и эмулятор SHALL пересоздаваться при смене виджета или сценария (`key`), а смена `hostContext` SHALL приводить к `emulator.setHostContext` без пересоздания.

#### Scenario: Смена сценария
- **WHEN** пользователь выбирает сценарий `error`
- **THEN** iframe перемонтируется, виджет заново проходит handshake и получает мок-ошибку

#### Scenario: Смена темы без перезагрузки
- **WHEN** пользователь переключает тему
- **THEN** виджет получает `host-context-changed`, iframe не перемонтируется

### Requirement: Live-сценарий
При сценарии `live` студия SHALL подключиться к MCP-серверу по адресу из `?server=` (по умолчанию `http://localhost:3100/mcp`) через streamable HTTP, найти ресурс по MIME `text/html;profile=mcp-app` (запасной вариант — префикс `ui://`), прочитать его HTML и использовать как источник виджета, а вызовы инструментов проксировать через passthrough.

#### Scenario: Example server
- **WHEN** сервер на :3100 запущен и выбран `live`
- **THEN** виджет рендерится из ресурса сервера, `get_metrics` возвращает данные сервера

#### Scenario: Другой сервер
- **WHEN** студия открыта с `?server=http://127.0.0.1:3200/mcp`
- **THEN** в live-режиме показывается виджет этого сервера

### Requirement: Ошибки инструментов в live-режиме
Результат с `isError: true` SHALL превращаться в `RpcError(TOOL_ERROR, текст content)`; при наличии `structuredContent` виджету SHALL возвращаться он, иначе — весь результат.

#### Scenario: Инструмент fail
- **WHEN** сервер отвечает `isError: true` с текстом `Intentional failure`
- **THEN** виджет получает JSON-RPC-ошибку с кодом `-32000` и этим текстом

### Requirement: Недоступный сервер
Если подключение не удалось, студия SHALL показать причину и подсказку, как запустить сервер или указать другой через `?server=`, вместо пустого холста.

#### Scenario: Сервер не запущен
- **WHEN** выбран `live`, а порт не слушается
- **THEN** на холсте текст `Can't reach the MCP server: …` с подсказкой

### Requirement: Панель трассы
Панель SHALL показывать счётчик записей, строку на событие с направлением, методом или `#id`, видом; невалидные записи SHALL выделяться и показывать причину; строка SHALL раскрываться в JSON payload; кнопка `Clear` SHALL очищать лог.

#### Scenario: Раскрытие и очистка
- **WHEN** пользователь раскрывает строку `ui/initialize` и нажимает `Clear`
- **THEN** в раскрытой строке виден `"jsonrpc"`, после очистки строк нет и показан текст-заглушка
