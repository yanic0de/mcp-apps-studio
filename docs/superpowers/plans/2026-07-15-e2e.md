# Playwright E2E Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Real-browser e2e (`e2e/`, Playwright, chromium-only): демо-виджет через настоящий postMessage/sandbox, live-цепочка studio↔iframe↔example-server, CLI c токен-аутентификацией и виджетами библиотеки.

**Architecture:** Три webServer'а в конфиге: (1) vite dev студии :4173 — demo-fallback сценарии; (2) example-server :3100 — live; (3) CLI :4499 поверх свежих билдов app+components с фиксированным токеном через новый флаг `--token` (иначе токен не достать из stdout webServer'а). В iframe лезем `frameLocator` — Playwright видит sandboxed srcdoc-фреймы в Chromium.

## Global Constraints

- Chromium only (CSP-профили — Chromium-only и так; матрица браузеров — не MVP).
- `--token` в bin: только явное значение для автоматизации; генерация по умолчанию не меняется.
- Никаких sleep — только web-first assertions Playwright.
