First public release: Storybook + Playwright for MCP Apps widgets. `npx mcp-apps-studio init` scaffolds stories, `mcp-apps-studio` serves the studio, `mcp-apps-studio test` runs every story headlessly in CI. `@mcp-apps-studio/widget-runtime` adds `connectWidget` and React hooks on top of the official ext-apps `App`.
